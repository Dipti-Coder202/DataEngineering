## Engineering approach

- Design pipelines for safe retries and predictable recovery.
- Keep secrets and generated runtime state out of Git.
- Reconcile row counts and business metrics across processing layers.
- Quarantine invalid data instead of silently discarding it.
- Optimize only after understanding scans, shuffles, partitions, and reuse.
- Document setup, architecture, trade-offs, and manual verification commands.
